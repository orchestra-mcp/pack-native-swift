# orchestra-mcp/pack-native-swift

Swift and macOS/iOS native plugin development agents

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-native-swift
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-native-swift")
```
